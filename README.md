⚡ PYSECOPS TOOLKIT

Outils d'audit et de sécurité - by hyacinthe

PySecOps est une suite d'audit de sécurité en ligne de commande (CLI) développée en Python. Elle permet d'effectuer des scans de ports, d'analyser des logs d'intrusion, et de détecter des vulnérabilités web de manière automatisée.
🛠️ Modules

    Scanner de ports (Réseau) : Analyse des 1024 premiers ports TCP.
    Analyseur de logs (Forensic) : Détection d'IPs suspectes et tentatives de brute-force via Regex.
    Outils SecOps : Génération de mots de passe sécurisés et hachage SHA-256.
    Scan de vulnérabilités (Web) : Audit des en-têtes HTTP (Clickjacking, XSS, Divulgation de techno).
